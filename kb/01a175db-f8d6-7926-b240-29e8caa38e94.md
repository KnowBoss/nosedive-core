# Baseline

Takes a repo from legacy nosedive's config to one that lists its roots. A config that already lists `roots` is left as it is.

- **Root**: the doc the config names as `backlog`, in its `kb` (`./kb` by default). A root of kind `memo` or `base` becomes kind `base`, its `meta` dropped, since base declares none; any other kind is kept.
- **Workspace**: the config's `workspace`, else `./workspace` when that directory exists.
- **Kinds and repos**: every doc of kind `kind` or `repo` in the kb moves into `.nosedive/kinds/` or `.nosedive/repos/`; links to them still resolve, by the id in their keys.
- **Config**: `id` is the root's id, so home copies keep their names; `roots` lists the root; `workspace` is set as above; `backlog` and `kb`, which `roots` replaces, are removed, and every other key is kept.
