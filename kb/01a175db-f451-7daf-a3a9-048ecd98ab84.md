# Run migrations

Brings a repo to today's shape. It reads `last-migration` from the repo's config and runs each migration after it, in chain order, or every migration when there is none; each that changes anything is committed alone, as `migrate: <name>`. Then it records the last migration of the chain as `last-migration` and commits that. A repo whose config names a migration core does not have was migrated by a newer core: it refuses, naming it. A repo with no config has nothing to migrate. It returns the names of the migrations that changed something.
