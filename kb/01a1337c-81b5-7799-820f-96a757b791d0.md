# Build cape

The clone lives under `.nosedive/capes/src/<repo id>` and is fetched on each build. The repo must pass the cape source check. Each `a<id>` it imports from `nosedive-core` must be a doc of the running core and a link of one of its own action docs; the import is then bundled as a lookup of `uuidv5(<doc id>, <core id>)` in the running core's index, so the built cape refuses to run against any other core. Building needs esbuild installed next to nosedive.
