# Build cape

The clone lives under `.nosedive/capes/src/<repo id>` and is fetched on each build. The repo must be a cape, its root of kind `cape`, and pass the cape source check.

A cape imports `i<id>` from `nosedive-core`, or from another cape by its repo's name in the bridge kb (`from "nosedive-crud"`). Each cape it imports is built first, at the ref the bridge's config uses for that repo, or its trunk when config names none; capes that import each other in a cycle are refused. Each imported id must be a doc of what it comes from and a link of one of the cape's own action docs. The import is bundled as a lookup of `uuidv5(<doc id>, <id of what it comes from>)` in that cape's index, so the built cape refuses to run against any other core or other builds of the capes it imports.

A cape whose id is already built and recorded is not built again. Building needs esbuild installed next to nosedive.
