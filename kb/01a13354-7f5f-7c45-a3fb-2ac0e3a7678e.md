# Scaf

Run in a cape repo. For the action `<quid>`, or every action in the repo's kb, scaf writes each missing entrypoint, usage impl and test as a stub, and never overwrites one. It rewrites each doc's `## Code` section, which links those files. It then lists what it could not fix by itself: an entrypoint that does not call one of its usage impls yet, and files no doc accounts for.

The stubs throw or are marked todo, so a scaffolded action builds and fails loudly until it is written.
