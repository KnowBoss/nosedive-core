# Cape

A repo is a cape when its root, the doc its config's `root` names, is of this kind: `nosedive seed --root-kind cape` makes one. Only a cape is built by seed for the actions config names, or scaffolded by scaf; any other repo is refused, so config cannot point an action at a repo that merely has a kb.

The schema is closed and declares nothing yet. What is true of a cape as a whole, rather than of one action, belongs here: in time, whether it is paid, the crew it is built for, the cores it supports.
