# Cape

A repo is a cape when its root, the doc its config's `root` names, is of this kind: `nosedive seed --root-kind cape` makes one. The root's name, which seed takes from the repo folder, is the cape's name: `nosedive cape <remote>` registers the repo by it. Only a cape is added by `cape`, built by seed, or scaffolded by scaf; any other repo is refused, so config cannot list a repo that merely has a kb as a cape.

The schema is closed and declares nothing yet. What is true of a cape as a whole, rather than of one action, belongs here: in time, whether it is paid, the crew it is built for, the cores it supports.
