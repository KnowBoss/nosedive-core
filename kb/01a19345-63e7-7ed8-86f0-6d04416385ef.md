# Local capes

## Usage

A hero lists a local cape's root doc in its config `roots` (cape-roots), and core finds local capes there, by the root doc's kind, never by a directory name. A local cape is a root other than the primary of core's kind `cape` whose directory is held by a nested seeded repo: the nearest `.nosedive/config.yaml` above the root's directory is not the hero's. It returns each with the root's id and path, the cape's name (the root doc's) and its directory.

`nestedRoot` is the test for one root, without reading its doc. Whatever walks a hero's roots (find-root, seed's tree render, the migrations, the feat walk) uses it to leave these roots to their capes.
