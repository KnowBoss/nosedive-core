# Commit message

Every commit nosedive makes ends with one `Co-Authored-By: nosedive <core version> <noreply@nosedive.dev>` trailer, as legacy nosedive's did. The default function adds it to a message through `git interpret-trailers`, so it joins any trailers the message has and starts a block when there are none; a message that carries a nosedive co-author already, of any version, is returned as it is. `coAuthor` is the trailer, `isCoAuthor` tells whether a trailer is one, and `hasCoAuthor` whether a message carries one, which land uses to stamp a commit it lands only when it lacks one.
