# Load source cape

The index is the one the build bakes in, built at runtime from each entrypoint the docs name; a missing entrypoint is left out, for the check to report and scaf to write. Its commit and version read `source`. A cape repo's own test harness loads itself with this, and core with its own built exports, so tests drive actions through the launcher exactly as a run would.
