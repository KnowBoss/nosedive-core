# Drop kb docs

Finds each doc as crud's edits do, then reads every doc in the bridge's kb and the kbs of the repos checked out in its workspace. It refuses while a doc outside the given set links to one inside it, or mentions its id in its body, or a config lists it among its roots, naming each; links and mentions among the given docs do not count, so a set whose docs all mention each other can still go. A doc of a durable kind, read in the terms of its holder (see find-kind), is refused unless `hard` is set. It deletes the files and commits them in each repo they live in, one commit per repo, and returns their paths relative to the bridge.

`crud --drop` calls it with one doc, `crud --drop-list` with many.
