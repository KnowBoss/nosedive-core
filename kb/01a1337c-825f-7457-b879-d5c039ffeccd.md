# Find cape

It looks through the [configured capes](01a141f8-69bf-7f76-b5bc-81aa991ff9b9.md) for one whose build lists the action, so a cape not built for this core provides nothing, and `help` says to run `nosedive seed`. It loads that cape with load-cape. Given the name of a cape, as `<cape>:<action>` gives it, it loads that one, refusing one not configured, not built, or without the action; given none, it refuses an action two configured capes provide, naming each as `<cape>:<action>`.
