# Find cape

Config `actions` maps an action to `<repo>` or `<repo>@<ref>`, the repo by its name in the bridge kb. A ref of 40 hex characters is a commit, and names its cape directly; anything else, or none, means the newest cape the manifest records for that repo and ref with this core. A cape that is not built throws, naming `nosedive seed`, which builds it. Before importing a cape, it publishes the running core as `globalThis.__nosediveCore`, which the cape's imports from `nosedive-core` read.
