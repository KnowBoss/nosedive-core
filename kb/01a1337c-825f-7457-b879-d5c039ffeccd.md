# Find cape

It looks through the [configured capes](01a141f8-69bf-7f76-b5bc-81aa991ff9b9.md) for one whose build lists the action, so a cape not built for this core provides nothing, and `help` says to run `nosedive seed`. A cape whose bundle, or one it imports, is missing throws, naming seed too. Before importing a cape, it publishes the running core as `globalThis.__nosediveCore` and loads the capes it imports into `globalThis.__nosediveCapes`, by id, which is where the cape's imports read them.
