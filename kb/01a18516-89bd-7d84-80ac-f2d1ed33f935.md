# Attach cape

## Usage

A repo kind gate: `<repo>` is the quid of the repo doc `crud repo` registered. It clones the repo's origin where build-cape keeps its sources, refuses it unless its root is a `cape`, builds it against the running core at `--ref`, or its trunk, and links the repo doc from the selected base as `.cape`, carrying `ref` when given. A cape the base already wears is refused. The repo doc's name is the hero's own for the cape, its long name, whatever the hero called it; its short name is its root doc's, which only the cape chooses (cape-short-names). It prints the version and commit it built.

To detach it, `pass --detach-cape <repo>`; to forget the repo too, `crud --drop <repo> --hard`, since repo is a durable kind.
