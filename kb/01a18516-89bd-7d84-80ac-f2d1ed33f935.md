# Don cape

## Usage

Puts on a cape the hero has registered with `crud repo`: a repo kind gate, so `<repo>` is the repo doc's quid. It clones the repo's origin where build-cape keeps its sources, refuses it unless its root is a `cape` named as the repo doc is, builds it against the running core at `--ref`, or its trunk, and links the repo doc from the selected base as `.cape`, carrying `ref` when given. A cape the base already wears is refused. It prints the version and commit it built.

To take a cape off, `pass --doff-cape <repo>`; to forget the repo too, `crud --drop <repo> --hard`, since repo is a durable kind.
