# Doff cape

## Usage

Takes off a cape the selected base wears: a repo kind gate, so `<repo>` is the repo doc's quid. It drops the base's `.cape` link to the repo doc; the doc and the cape's builds stay, since the doc may name the repo for other reasons and builds are only cache. A cape the base does not wear is refused.
