# Detach cape

## Usage

A repo kind gate: `<repo>` is the repo doc's quid. It drops the target root's `.cape` link to the repo doc; the doc and the cape's builds stay, since the doc may name the repo for other reasons and builds are only cache. A cape the target root does not wear is refused.
