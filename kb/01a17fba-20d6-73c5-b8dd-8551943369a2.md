# Dehydrate repo

It takes the ship, the repo's doc and `{ discard }`. It refuses, keeping the checkout, while the checkout has uncommitted changes or untracked files, and while it has ignored files (a `.env`, build output) unless `discard` is set, which removes the ignored ones, never the untracked; each refusal lists the files.

A checkout on a branch force-pushes it to its packed ref on origin, `refs/nosedive/<branch>`, whose commits are the branch's alone; only land moves a work branch on origin. A detached checkout whose commit origin has goes without a push, and one holding commits origin lacks is refused, naming them. A push origin rejects refuses, keeping the checkout. Then the worktree is removed; the user's cache keeps the branch and its commits for the next [hydrate-repo](01a15baf-13e2-7bd8-8dc8-80d4871f2210.md). A repo with no checkout is said to have none.
