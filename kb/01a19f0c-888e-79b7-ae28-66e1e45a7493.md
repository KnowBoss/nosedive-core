# Durable from done when

A kind is durable when its doc has no `## Done when` section (see kind), so `meta.durable` says nothing a kind doc's body does not, and the kind schema no longer allows it. This migration drops it from every kind doc the repo declares: those in its `.nosedive/kinds/`, and any `kind` doc of core's left in a root's kb, a seeded repo nested in it being left to its own seed.

- **`durable: true`, no Done when**: the flag goes; the kind stays durable.
- **`durable: false`, with a Done when**: the flag goes; the kind stays passing work.
- **`durable: false` (or anything but true), no Done when**: the flag goes and the doc gains `## Done when` saying "Not yet said: ask the pilot.", so the kind stays passing work until the pilot says when one of it is done.
- **`durable: true` with a Done when**: the doc contradicts itself and only the pilot can say which it meant. The migration names each such doc, says how to settle it, and writes nothing, waiting as a migration does, so seed runs it again once the doc is settled.

A kind doc with no `durable` is left as it is, so the migration is safe to run again. It says what it did with each kind it changed. A cape built from a commit whose kind docs still carry `durable` is refused (see build-cape), so a cape is migrated, pushed and its pin bumped before a hero wears it with this core.
