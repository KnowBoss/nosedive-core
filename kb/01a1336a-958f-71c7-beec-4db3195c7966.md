# Launch

Core's actions come first and are never shadowed: only a name core lacks goes to the cape the bridge config's `actions` names for it. `help` lists core's top-level actions, then each action config names, from its cape when built or as not built; an action under another action runs by name but is not listed. `<action> --help` lists its usages, and `--more` adds its doc's body. Errors print as `nosedive: <message>` with exit code 1.

The same file holds the types every cape is written against (`Ctx`, `ActionCall`, `Cape`) and `consoleCtx`, the ctx of a real command line.
