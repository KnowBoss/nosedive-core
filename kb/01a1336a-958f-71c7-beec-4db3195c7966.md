# Launch

The first cape that indexes the name wins, and core is loaded first, so no other cape can shadow a core action. `help` lists every user action; `<action> --help` lists its usages, and `--more` adds its doc's body. Errors print as `nosedive: <message>` with exit code 1.

The same file holds the types every cape is written against (`Ctx`, `ActionCall`, `Cape`) and `consoleCtx`, the ctx of a real command line.
