# Find bridge

The bridge is the repo whose config nosedive resolves when it runs: the nearest base above the directory, unless that base is itself checked out in another base's workspace, in which case that other base. With no base above, it is the nearest repo with a `.nosedive/config.yaml`. Each repo's own config is read with read-repo-config: its kb, its root (`root`, or `backlog`, its older name), and, for a base, its workspace.
