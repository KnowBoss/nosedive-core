# Find bridge

The bridge is the repo whose config nosedive resolves when it runs: the nearest repo above the directory with a `.nosedive/config.yaml`, read with read-repo-config: its id, its roots and kb, and its workspace. A workspace checkout is never a hero, and launch refuses to run from inside one; `insideWorkspace` names the hero and the checkout a directory sits in, for that refusal.
