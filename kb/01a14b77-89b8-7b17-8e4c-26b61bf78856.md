# Hydrate

The repo kind links this gate, so `nosedive pass --hydrate <quid>` checks out any repo in the bridge's kb. The bridge keeps one bare cache per repo at `.nosedive/cache/<repo id>.git`, or `<repo id>` alone where legacy left one (legacy caches turn on per-worktree config, so each new worktree is told it is not bare), which seed has git ignore, and only the workspace holds checkouts: each is a worktree of its cache at `<workspace>/<name>`, on `meta.trunk`, else the branch the source's HEAD names.

Each hydrate fetches the cache's branches as `origin/*`, from the repo's home copy when the bridge has a `home`; when that copy is missing or the fetch fails, it warns and fetches from the repo's first remote instead. A repo already checked out is left as it is, and a doc that is no repo is refused.
