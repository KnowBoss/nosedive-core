# Mint kb doc

Its name is the one given, or the gist's first words slugged with the id's last six characters, so names stay unique. The gist is written quoted, whatever it holds, and the body starts with a heading: the title given, else the name given, its hyphens spaces and its first letter capital (`build-ship` is titled `Build ship`), else the gist. A tree lists docs by their headings, so a doc named by hand is listed by that name. It refuses to overwrite a doc. Committing is the caller's: seed commits a new root with the rest of its setup, crud and cape commit theirs alone.
