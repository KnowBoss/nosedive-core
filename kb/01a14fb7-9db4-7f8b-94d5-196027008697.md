# Builds a base's own actions from its working tree into .nosedive/capes/<id>.js and loads them, or returns nothing when it has none

## Whole

Like a cape, a hero's code builds whole: its npm packages are installed with install-cape-packages first, and the build id covers its lockfile and every file under `assets/` as well as its code docs and `src/`.
