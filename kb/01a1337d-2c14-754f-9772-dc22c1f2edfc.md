# Find repo doc

Looked for only among the docs the hero keeps in `.nosedive/repos/`, which are core repo docs by place whatever their root kind says. Docs in a root kb are never registered repos. The remote is `meta.remotes.origin`, a path being relative to the bridge root; a repo without one is refused.
