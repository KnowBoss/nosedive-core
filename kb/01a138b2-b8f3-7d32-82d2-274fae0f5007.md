# Cape tests pass

Core's own gate, which the cape kind links as `test.gate`, so `nosedive pass --test <root>` runs any cape's tests, with no link of its own. It runs the tests of the repo the passing doc lives in with run-repo-tests, so a repo needs no gate code of its own to be tested.
