# Edit kb docs

crud's edits all run in one. `doc(id)` finds a doc as crud does (the bridge, then the workspace's repos) once per edit, so later changes see earlier ones, and refuses a doc git does not track before anything is written. `change(doc)` marks it to be written. `commit()` writes the marked docs whose text changed and commits each repo's together: `crud(<id>): updated <kind> <name>` for one doc, else `crud: updated N docs`, unless it is given a message, as pass gives `pass(<name>): <sect>`. A doc is written with its frontmatter in KINGSMETAL order, so an edit also orders the doc it touches. It refuses a doc whose scopes repeat a key as it would be written, so an edit can repair one. It returns the marked docs' paths relative to the bridge.
