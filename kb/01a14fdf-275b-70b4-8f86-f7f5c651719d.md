# The kind a kb doc's frontmatter names, read from the head of its file, so a doc of another kind is never read whole

## Head

Reads the file in chunks until its frontmatter's `kind:` line, and stops there: frontmatter puts `kind` first, so one small read usually settles it. A file that does not open with frontmatter, or whose frontmatter ends without a kind, has none.
