# Load cape

Before importing a cape, it publishes the running core as `globalThis.__nosediveCore` and loads the capes it imports into `globalThis.__nosediveCapes`, by id, which is where the cape's imports read them; each loads once per process. A cape whose bundle, or one it imports, is missing throws, naming seed.
