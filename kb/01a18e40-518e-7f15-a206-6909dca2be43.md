# List kinds

The kinds a repo can name, which `nosedive crud` prints. The first group is the repo's own: its root's name, and the kinds it declares, in its `.nosedive/kinds/`, each reached by its bare name. Then one group for each cape the repo wears, core first: the capes loaded, and those its build manifest records but which are not loaded. A group has its owner's seeded id, its short name (its cape root doc's name) and its long name (the name of the repo doc that registers it), and every kind it declares with the spellings that reach it: `<short>:<name>`, `<long>:<name>` and `<quid>:<name>`. A name that two capes answer to is left out of both, so a spelling reaches one kind; the quid never clashes.

A kind's meta is its declaration (schema, durable, links, id), its name and its owner, the version a build recorded, its doc's file in its repo, and where its repo's history can be asked: the cape's source when it is run from source, else the hero's checkout of it, else the clone its build was made from, with the repo doc that registers it.
