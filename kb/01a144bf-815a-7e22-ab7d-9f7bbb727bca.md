# Function

The plain case of code in a cape: what an [action](01a13354-7d34-72f3-ad11-9c44b4d5de6e.md) or another function calls, with whatever arguments it needs. It has no usages, so users cannot call it; something that users can call is an action instead.

Its name says what it does (`match-usage`), and its body says what it is for. Its code is `src/i<h>.ts`, exporting `i<h>`, and its tests are `test/t<h>.test.ts`, with `h` its doc id without dashes. It hangs in the tree under its only user, or in a lib group once it has two.
