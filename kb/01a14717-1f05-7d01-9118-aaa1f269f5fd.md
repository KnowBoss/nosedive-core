# Find kind

Looks for a `kind: kind` doc of that name in each kb directory given, in order, then, given a ship, among the kinds it keeps in `.nosedive/kinds/`, then in the loaded capes' `kinds`, then, given a ship, in the kinds its configured capes' builds recorded, so a core action like crud knows a cape's kinds without loading the cape; and returns the first declaration's meta: its `schema`, and `durable` when it says so, with the declaration's `links`, which name the gates its docs pass through. Nothing declares the kind when it returns nothing. Check-meta validates against the schema; crud's `--drop` reads `durable`.
