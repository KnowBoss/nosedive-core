# Find kind

Looks for a `kind: kind` doc of that name in each kb directory given, in order, then in the loaded capes' `kinds`, and returns the first declaration's meta: its `schema`, and `durable` when it says so. Nothing declares the kind when it returns nothing. Check-meta validates against the schema; crud's `--drop` reads `durable`.
