# nosedive-core

## Actions

- [Cape](01a141f8-69c1-7bfe-afc1-9e0966a6a6be.md): Lists the capes this bridge uses, adds one from its remote, or drops one
- [Crud](01a13354-7dea-7604-b903-b94a5aca2b83.md): Reads, mints and edits kb docs
  - [Crud edit](01a14b30-ecc0-7ea1-8999-d6255d636e39.md): Applies one crud edit, named as its flag, to a doc in an edit
  - [Drop kb docs](01a1480b-f832-7315-b113-47f5e5f118a1.md): Deletes the given docs together in one commit, refusing while any doc outside them links to or mentions one, or one is durable without hard
  - [Edit kb docs](01a14ab1-d367-71ee-a2bc-6f13bdeb0526.md): Opens an edit of kb docs: finds each doc once, refuses one git does not track, and writes and commits what changed, one commit per repo
  - [Merge keyed entries](01a13358-8b1f-7d4e-a13f-1b5e79f02e4c.md): Merges a mapping into a list of one-key entries, the shape of scopes and links
  - [Read source](01a13354-8731-7576-a0af-d03506ef5555.md): Parses YAML or JSON from stdin when the value is `-`, or from the file the value names
  - [Read text](01a14717-2380-7d6e-8ef2-28ad9472fff7.md): The text a source names: stdin when it is -, else the file at that path
  - [Split title](01a14717-207d-7277-a493-c7adb10ed32f.md): A doc body's title, the # heading that starts it, and everything under it; nothing when it has no title
  - [Update kb doc body](01a14717-2214-79dd-bcac-26cce4b2a059.md): Replaces a doc's body in an edit with a function of its current body
  - [Update kb doc field](01a13358-8bcc-7f8b-ae72-5ff70d8f6800.md): Replaces one frontmatter field of a doc in an edit with a function of its current value
- [Launch](01a1336a-958f-71c7-beec-4db3195c7966.md): Runs one command line: finds the action it names in the loaded capes, matches a usage, and calls the action's entrypoint
  - [Find cape](01a1337c-825f-7457-b879-d5c039ffeccd.md): The configured cape whose build provides an action, loaded against the running core, or nothing when none does
  - [Load cape](01a14b30-eb0e-72e2-8934-c918000a26ac.md): Loads a built cape after the capes it imports, each published where their imports look for it
  - [Match usage](01a13354-8243-7c9e-b145-885f65f12aa1.md): Which of an action's usages an argv matches, and the arguments it binds
- [Mint](01a13565-d94b-7458-86f9-e2909a9aae2a.md): Prints new uuid v7 ids, one per successive millisecond
- [Pass](01a14b30-ee4e-722f-961d-32bbb99bdb8a.md): Passes a doc through the gates its kind and it link in one sect
  - [Cape tests pass](01a138b2-b8f3-7d32-82d2-274fae0f5007.md): Every test in a cape repo passes, run against the running core and the capes beside it
    - [Run repo tests](01a138b2-b8f1-75bc-9524-2dc33d92138b.md): Runs a cape repo's tests in their own node process, against the running core and the capes checked out beside it
- [Scaf](01a13354-7f5f-7c45-a3fb-2ac0e3a7678e.md): Writes the files a cape's action docs call for and do not have yet
- [Seed](01a13354-7ea8-7883-b6ac-c99ddff5d5a8.md): Makes the current git repo a bridge, or brings an existing bridge's setup up to date
  - [Render tree](01a14a55-0446-7ef0-8586-b828ebabc148.md): A root doc's body as its tree: one section per feat rel group, each doc with its child.feat docs beneath it
  - [Run migrations](01a175db-f451-7daf-a3a9-048ecd98ab84.md): Brings a repo to today's shape by running the migrations it has not run
    - [Baseline](01a175db-f8d6-7926-b240-29e8caa38e94.md): Takes a repo from legacy nosedive's config to one that lists its roots

## Kinds

- [Action](../.nosedive/kinds/01a13354-7d34-72f3-ad11-9c44b4d5de6e.md): A function a user can call: its usages are its contracts, and its code routes each to its implementation
- [Base](../.nosedive/kinds/01a13cb4-6b7e-71eb-b19f-5d64d7e20b6c.md): The root of an older data repo: docs only, which hero repos check out and write to
- [Cape](../.nosedive/kinds/01a13a6a-3d62-77fc-a86c-9ed9ed3f8be4.md): A root that makes its repo a cape: the feats it reaches are the actions the cape adds to nosedive
- [Function](../.nosedive/kinds/01a144bf-815a-7e22-ab7d-9f7bbb727bca.md): A function other code calls, with plain arguments: users cannot call it, and it has a test
- [Kind](../.nosedive/kinds/01a138b2-b8e9-7f63-9068-f1439b9cb8c9.md): Declares a kind: meta.schema is a JSON Schema (draft 2020-12) for the meta of every doc of that kind
- [Memo](../.nosedive/kinds/01a138b2-b8ea-70da-8613-832fec741f69.md): The free-form doc: a note, a root, a grouping; its meta holds whatever its writer needed
- [Migration](../.nosedive/kinds/01a175db-f05a-74f3-884a-fbf490a52104.md): A step that brings a repo from one shape to the next
- [Repo](../.nosedive/kinds/01a138b2-b8eb-79e8-9d77-6e8379ec18e3.md): Names a repository a bridge works in: where it is cloned from, and where it is checked out
- [Root](../.nosedive/kinds/01a174b6-3f07-72d9-b54b-90e36f677589.md): What a repo's docs hang from when nothing more is said
- [Ship](../.nosedive/kinds/01a15ba9-63c8-73cf-ae4d-d7b2dfc01be6.md): The root of an older repo that worked: its meta.workspace is where repos are checked out

    - [Cape id](01a1337c-8060-75ca-96d6-37c9ece7316e.md): A cape's id: uuidv5 of its commit, the core cape's id and the ids of the capes it imports, in its repo's id
  - [Builds a base's own actions from its working tree into .nosedive/capes/<id>.js and loads them, or returns nothing when it has none](01a14fb7-9db4-7f8b-94d5-196027008697.md): Builds a hero's own actions from its working tree into .nosedive/capes/<id>.js and loads them, or returns nothing when it has none

  - [Configured capes](01a141f8-69bf-7f76-b5bc-81aa991ff9b9.md): The capes a bridge's config lists, each with its repo doc and its newest build for the running core
  - [Describe cape source](01a13354-87e4-7754-9d84-a6fc2c901bf6.md): A cape repo's action docs, as the cape will export them, with the entrypoint file each one names
    - [Usage id](01a13354-8178-7393-9894-1123114401ad.md): The hex id of one usage of an action: uuidv5 of the usage text, whitespace collapsed, in the action doc's id
  - [Installs the npm packages a cape's lockfile pins, without running their scripts, unless that lockfile is installed already](01a15191-3e57-7208-8ae9-3b14a4a3f120.md): Installs the npm packages a cape's lockfile pins, without running their scripts, unless that lockfile is installed already
  - [Load source cape](01a13541-9cdf-7f3b-a72a-31c4092c5bb5.md): A cape repo's actions loaded straight from its source, as a cape with the given id, for development and tests
  - [The sect and kind a gate usage starts with, pass --<sect> <kind>, or nothing for any other usage](01a14fb0-9217-7d36-a478-d40a47166c97.md): The sect and kind a gate usage starts with, pass --<sect> <kind>, or nothing for any other usage
- [Ids](01a14237-2b56-7302-a79c-fe6b14b98ea5.md): How ids are made: time-ordered for new docs, namespaced for the same name in the same space
  - [Mint uuid](01a13354-80c7-76ba-8945-020d0af333eb.md): A new time-ordered uuid (v7) for a doc that needs an id of its own
  - [Namespaced uuid](01a13354-8014-7d06-8652-8aee80f8ee34.md): uuidv5(name, namespace): the same uuid wherever the same name meets the same namespace
- [Kb](01a13565-d897-7af6-9458-c82ef6e77bee.md): How kb docs are found, read, checked, minted, written and merged
  - [Check meta](01a138b2-b8ef-7e80-97e1-9d599ba39bcc.md): Checks a doc's meta against its kind's schema, wherever that kind is declared, or says nothing declares it
  - [Find kb doc](01a13354-845c-7253-a55b-60bba87285d8.md): The doc with a given id in a kb directory, or nothing
  - [Find kind](01a14717-1f05-7d01-9118-aaa1f269f5fd.md): A kind's declaration: its meta (schema, durable) from the first kb that declares it, else the first loaded cape

  - [Mint kb doc](01a141f8-69c0-7c4d-a828-8927a559c8ae.md): Writes a new kb doc: its kind, a minted id unless given one, a name, its gist, and any meta
  - [Read kb doc](01a13354-82f8-76d6-808a-ec457f512e80.md): Splits a kb doc's text into its frontmatter and body
  - [The kind a kb doc's frontmatter names, read from the head of its file, so a doc of another kind is never read whole](01a14fdf-275b-70b4-8f86-f7f5c651719d.md): The kind a kb doc's frontmatter names, read from the head of its file, so a doc of another kind is never read whole
  - [Write kb doc](01a13354-83aa-776c-b84d-f698b04adc06.md): Writes a kb doc's frontmatter and body back to its file

  - [Checkout path](01a13c76-0de8-7562-b473-8946402010b8.md): Where a registered repo is checked out: <workspace>/<name>, in a hero repo
