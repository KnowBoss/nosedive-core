# nosedive-core

## Action

- [Crud](01a13354-7dea-7604-b903-b94a5aca2b83.md): Reads, mints and edits kb docs
- [Launch](01a1336a-958f-71c7-beec-4db3195c7966.md): Runs one command line: finds the action it names in the loaded capes, matches a usage, and calls the action's entrypoint
  - [Cape index](01a13358-8c79-71b5-b116-d9c8c1706e04.md): The index entries of a cape: each action's name keyed to its doc id, and its doc id keyed to its entrypoint
  - [Find cape](01a1337c-825f-7457-b879-d5c039ffeccd.md): The cape a bridge's config names for an action, loaded against the running core, or nothing when the config names none
    - [Cape id](01a1337c-8060-75ca-96d6-37c9ece7316e.md): A cape's id: uuidv5 of its commit, the core cape's id and the ids of the capes it imports, in its repo's id
    - [Cape manifest](01a1337c-810a-7456-876b-831d0c873396.md): The capes a bridge has built, as recorded in .nosedive/capes/manifest.json, optionally recording one more first
    - [Find repo doc](01a1337d-2c14-754f-9772-dc22c1f2edfc.md): A repo registered in the bridge kb, by name: its id and the remote to clone it from
  - [Match usage](01a13354-8243-7c9e-b145-885f65f12aa1.md): Which of an action's usages an argv matches, and the arguments it binds
- [Mint](01a13565-d94b-7458-86f9-e2909a9aae2a.md): Prints new uuid v7 ids, one per successive millisecond
- [Scaf](01a13354-7f5f-7c45-a3fb-2ac0e3a7678e.md): Writes the files a cape repo's action docs call for and do not have yet
  - [Check cape source](01a13354-8893-7f1c-8c39-83dd2950028e.md): Everything in a cape repo that its action docs do not account for, or that they name and is missing
  - [Code section](01a1336c-b234-701b-b033-8faf5183960c.md): An action doc's body with its generated `## Code` section, which links the action's entrypoint, impls and tests
  - [Describe cape source](01a13354-87e4-7754-9d84-a6fc2c901bf6.md): A cape repo's action docs, as the cape will export them, with the entrypoint file each one names
  - [Load source cape](01a13541-9cdf-7f3b-a72a-31c4092c5bb5.md): A cape repo's actions loaded straight from its source, as a cape with the given id, for development and tests
  - [Usage id](01a13354-8178-7393-9894-1123114401ad.md): The hex id of one usage of an action: uuidv5 of the usage text, whitespace collapsed, in the action doc's id
- [Seed](01a13354-7ea8-7883-b6ac-c99ddff5d5a8.md): Makes the current git repo a bridge, or brings an existing bridge's setup up to date
  - [Build cape](01a1337c-81b5-7799-820f-96a757b791d0.md): Clones a cape repo at a ref into the bridge, checks it, and builds it against the running core and the capes it imports into .nosedive/capes/<id>.js
- [Test](01a138b2-b8f2-768d-bbad-d90bc0c97ff3.md): Runs the test gates of a repo, or of a doc, from the bridge
  - [Repo tests pass](01a138b2-b8f3-7d32-82d2-274fae0f5007.md): Every test in the repo passes, run against the running core

## Kind

- [Action](01a13354-7d34-72f3-ad11-9c44b4d5de6e.md): What a cape provides: a user action when its meta lists usages, an internal function when it lists none
- [Cape](01a13a6a-3d62-77fc-a86c-9ed9ed3f8be4.md): The root of a cape repo: a repo whose actions extend nosedive itself
- [Gate](01a138b2-b8ec-7ec0-b4c2-7af6e7de01e4.md): A check that passes or fails: its code is src/a<id>.ts, and a doc links it as <verb>.gate for an action to run
- [Kind](01a138b2-b8e9-7f63-9068-f1439b9cb8c9.md): Declares a kind: meta.schema is a JSON Schema (draft 2020-12) for the meta of every doc of that kind
- [Memo](01a138b2-b8ea-70da-8613-832fec741f69.md): The free-form doc: a note, a root, a grouping; its meta holds whatever its writer needed
- [Repo](01a138b2-b8eb-79e8-9d77-6e8379ec18e3.md): Names a repository a bridge works in: where it is cloned from, and where it is checked out

## Lib

- [Core](01a13565-d897-7af6-9458-c82ef6e77bee.md): What every cape imports: the kb, id, git and merge functions that belong to no one action
  - [Check meta](01a138b2-b8ef-7e80-97e1-9d599ba39bcc.md): Checks a doc's meta against its kind's schema, wherever that kind is declared, or says nothing declares it
  - [Commit files](01a13354-8942-73b1-be25-3424511ba82c.md): Stages the given files in a repo and commits them with a message
  - [Find bridge](01a13354-85c6-7c95-b7ef-df2f0e03cfd6.md): The bridge a directory is in: its root, its config and its kb directory, or nothing
  - [Find kb doc](01a13354-845c-7253-a55b-60bba87285d8.md): The doc with a given id in a kb directory, or nothing
  - [Find root](01a13a6a-ba3a-7635-95bd-67a4ee4d47bf.md): The root doc of the bridge a repo directory is, with its kind, or nothing when the directory is no bridge or names no root
  - [Hydrate repo](01a138b2-b8f0-7934-95b6-6bc7935c93be.md): A repo registered in the bridge, checked out in its workspace: as it is when already there, else cloned at its trunk
  - [List kb docs](01a13354-850c-7ba3-ba5b-8ac41a7b6b11.md): Every doc in a kb directory, with its path, frontmatter and body
  - [Locate kb doc](01a138b2-b8ee-703c-ab22-7b010f588b6a.md): The doc with a given id in the bridge's kb or any repo checked out in its workspace, with the repo it lives in
  - [Merge keyed entries](01a13358-8b1f-7d4e-a13f-1b5e79f02e4c.md): Merges a mapping into a list of one-key entries, the shape of scopes and links
  - [Merge patch](01a13354-867d-7a52-8cba-d55b80708e50.md): Applies a JSON merge patch (RFC 7386) to a value
  - [Mint uuid](01a13354-80c7-76ba-8945-020d0af333eb.md): A new time-ordered uuid (v7) for a doc that needs an id of its own
  - [Namespaced uuid](01a13354-8014-7d06-8652-8aee80f8ee34.md): uuidv5(name, namespace): the same uuid wherever the same name meets the same namespace
  - [Read kb doc](01a13354-82f8-76d6-808a-ec457f512e80.md): Splits a kb doc's text into its frontmatter and body
  - [Read source](01a13354-8731-7576-a0af-d03506ef5555.md): Parses YAML or JSON from stdin when the value is `-`, or from the file the value names
  - [Run repo tests](01a138b2-b8f1-75bc-9524-2dc33d92138b.md): Runs a cape repo's tests in their own node process, against the running core and the capes checked out beside it
  - [Update kb doc field](01a13358-8bcc-7f8b-ae72-5ff70d8f6800.md): Replaces one frontmatter field of a bridge doc with a function of its current value, then writes and commits the doc
  - [Workspace repo](01a138b2-b8ed-7752-9797-3c2aad478c8f.md): A repo checked out in the bridge's workspace: its directory and its kb directory, or why it is not there
  - [Write kb doc](01a13354-83aa-776c-b84d-f698b04adc06.md): Writes a kb doc's frontmatter and body back to its file
