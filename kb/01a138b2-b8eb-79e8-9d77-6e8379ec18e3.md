# Repo

`remotes` maps a role to a URL or a path, a path being relative to the bridge; the first is the one cloned from, and a repo with none is cloned from its home copy. The home copy is never a remote: its place is derived from the bridge's config `home`, so `local` is no remote's role. A repo doc carries no path: a repo is checked out at `<workspace>/<name>`, the workspace being the base's.
