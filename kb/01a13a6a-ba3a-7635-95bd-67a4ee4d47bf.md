# Find root

Only the directory itself counts: a repo checked out inside some other bridge's workspace is not that bridge. The root is the first of the roots its config lists; given a kind, it is the first root whose kind, by doc-kind, is that kind of core's, which is how a cape is found among a repo's roots. A root a nested seeded directory holds, a local cape's (see local-capes), is not the repo's: it never makes a hero a cape. The kind it returns is the root's name for it when core's, else qualified by its owner.
