# Action

An action doc is the only way into a cape's code. Read the doc, then go to the files its id and usages name.

## Fields

- `name`: what users type (`crud`, `record.dive`), or a friendly description for an internal function (`load-a-kb-doc-by-id`).
- `gist`: one line on what it does.
- `usages` (optional): the contracts it supports, in docopt notation: `<arg>`, `<arg>...` (one or more), `[ ... ]` (optional), `--flag`, `--option <value>`. Each usage starts with the name. A value of `-` means stdin, by convention of the impl that reads it.
- `links` (optional): actions of other capes this one imports, as `<repo>:<doc-quid>`.

The body says what the action is for and how to use it.

## Files

With `h` = the doc id without dashes, and `u` = `uuidv5(<usage text, whitespace collapsed>, <doc id>)` without dashes:

| File | Exports | Holds |
|---|---|---|
| `src/a<h>.ts` | `a<h>` | The entrypoint. With usages: validates the matched usage's arguments and calls its impl. Without: the function itself. |
| `src/i<u>.ts` | `i<u>` | One usage's impl. |
| `test/t<u>.test.ts` | | That usage's tests, driven through the launcher with real arguments, so they prove the usage is reachable. |
| `test/t<h>.test.ts` | | An internal function's tests. |

Other code imports an action by its export, named for what it does where it is used: `import { a01a1335480147d0686528aee80f8ee34 as namespacedUuid } from "./a01a1335480147d0686528aee80f8ee34.ts"`. Search the kb for the id to learn what it does.

Editing a usage changes `u`, so its impl and test must move: a contract never changes silently. `nosedive scaf` writes the missing files; the build refuses a usage without its impl or test, and any file no doc accounts for.

## In a cape

A cape exports `id`, `name`, `commit`, `version`, `docs` and `index`. With `K` the cape id, `index[uuidv5(<name>, K)]` is the doc id of the action named `<name>`, and `index[uuidv5(<doc id>, K)]` is its entrypoint. Keys include `K`, which includes the commit, so code built against another cape never finds a stale entry.
