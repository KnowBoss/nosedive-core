# Describe cape source

Reads the repo's kb, the one its config names, else `kb/`, for its actions and functions, each with its usages and entrypoint, and its kinds, each with its meta and links. It learns each doc's kind from the head of its file with kb-doc-kind, and reads whole only the docs of those three kinds. Asked to read from `src/`, as a base's build and help are, it reads only the docs whose ids name a file there. Used by the build, the checks, scaf, and tests that run a cape from source.
