## Whole

The bundle carries everything the code imports: its npm packages, from the repo's `node_modules`, and its assets, the files under `assets/`. An asset imports as a string when it is text (`.html`, `.css`, `.svg`, `.md`, `.txt`), as bytes (`Uint8Array`) otherwise, and a `.client.ts` asset as the text of its own bundle for the browser, its imports and packages included. The bundle defines `require` for packages written as CommonJS. A package esbuild cannot bundle, such as a native addon, fails the build, naming it.
