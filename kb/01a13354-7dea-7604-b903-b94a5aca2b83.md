# Crud

`crud <quid>` prints a doc: from the bridge's kb when it has one, otherwise from the docs of the capes that are loaded, so a cape's own action docs can be read anywhere.

`crud <kind> <gist>...` mints a doc of that kind in the bridge's kb and commits it. Its name is `--name`, or the gist's first words slugged with the id's last six characters.

The `--meta`, `--scopes` and `--links` usages read a YAML or JSON mapping from `<source>` (`-` for stdin) and merge it into that field, then commit:

- `--meta`: a JSON merge patch onto `meta`.
- `--scopes` and `--links`: keyed by repo or link target; each value is merged onto that entry, a new key is appended, and `null` removes the entry.
