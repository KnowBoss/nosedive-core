# Checks a repo out into the ship's workspace, detached at its trunk, and says where and which trunk; a checkout already there is left as it is

# Hydrate repo

What the hydrate gate does, for code that is not a gate: the work loop checks out every repo a dive scopes this way. It takes the ship and the repo's doc, and returns the checkout's directory and the repo's trunk, `meta.trunk` or else the branch its source's HEAD names. The rules for the cache and the checkout are the [hydrate](01a14b77-89b8-7b17-8e4c-26b61bf78856.md) gate's.
