# Test

Always run from a base, never from inside the repo being tested. `<ref>` is a doc's quid or a repo's name.

- **A repo** (its name, or its repo doc's quid): the repo is checked out in the workspace if it is not already, and must be a bridge itself. Its root's `test.gate` links are run.
- **Any other doc**: its own `test.gate` links are run, against the repo it lives in.

Each gate is called with a `GateCtx`; a gate that throws fails. Core's gates, such as cape-tests-pass, are linked by id as `nosedive-core:<id>`. A gate of the repo's own is not run yet.
