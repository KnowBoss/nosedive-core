# Checkout path

The workspace is the config's `workspace`, `./workspace` by default. The repo whose doc's id is the config's `self` is checked out at `__self`, so its clone is always where nosedive looks for it, whatever it is named. A repo doc carries no path: this is the only place a checkout's location is decided.
