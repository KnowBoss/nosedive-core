# Check meta

The kind comes from the given kbs first, in order, then the loaded capes, core first, then the ship's configured capes (see find-kind). A kind nothing declares is not an error: it returns a warning, and the meta goes unchecked. A meta that breaks the schema throws, listing every problem.

## References to docs of a kind

A string property can declare `kind: <kind>` beside `type: string`, as `question: {type: string, kind: question}`: its value must be the quid of a doc of that kind, looked for in the doc's own kb and the bridge's first, then the ship and its workspace, then the loaded capes, a quid in capitals read as the lowercase one. A value that is no quid, names no doc or names a doc of another kind fails at the property's path. In a crud batch, it sees every edited doc's final kind, whatever the order of the edits, and a failure writes nothing. It checks the references a doc makes when that doc is checked; a doc it names changing kind or being dropped later checks nothing.
