# Check meta

The kind is spelled in the terms of the repo given, as find-kind takes it: bare for the repo's own, `<cape>:<kind>` for a cape's. A kind nothing declares is not an error: it returns a warning, and the meta goes unchecked. A meta that breaks the schema throws, listing every problem.

## References to docs of a kind

A string property can declare `kind: <kind>` beside `type: string`, as `question: {type: string, kind: question}`: its value must be the quid of a doc of that kind, looked for in the hero and its workspace, then the loaded capes, a quid in capitals read as the lowercase one. A doc is of the kind when its doc-kind is that kind's owner and name. A value that is no quid, names no doc or names a doc of another kind fails at the property's path. In a crud batch, it sees every edited doc's final kind, whatever the order of the edits, and a failure writes nothing. It checks the references a doc makes when that doc is checked; a doc it names changing kind or being dropped later checks nothing.

`checkDocMeta` checks a whole doc: its meta against its kind, read in the terms of its holder (see find-kind), and each scope entry's meta against the root's kind as the entry's key declares it. It returns the warnings.
