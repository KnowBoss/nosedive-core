# Base

`nosedive seed --root-kind base` makes one. Only a base has a workspace: seed writes the config's `workspace` (`./workspace`) and ignores it, and checking a repo out there, writing a doc into one with `crud <repo>:<kind>`, and `nosedive test <repo>` all refuse anywhere else.

Any other seeded repo is nosedive-aware without being a base: a cape, or an implementation repo with a kb. A base learns what such a repo is when it checks it out, from the kind of its root.
