# Base

# Base

A repo of data only: docs, and artifacts beside them. `nosedive seed --root-kind base` makes one, whose config names its root as `base: <quid>`. A base has no workspace, no capes, no actions and no kinds: a ship checks it out in its workspace, and a doc written into it is checked against the ship's kinds, then the capes'. Bases split data by scale or sensitivity, and a base's remotes decide where its data may live.

Before ships, a base was the repo a team worked from. A legacy `base` root that carries `meta.workspace` is still read that way, as a ship (see [ship](01a15ba9-63c8-73cf-ae4d-d7b2dfc01be6.md)); the schema keeps `workspace` for it.
