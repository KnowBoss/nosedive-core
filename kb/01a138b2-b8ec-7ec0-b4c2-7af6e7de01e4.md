# Gate

A gate is a function a check calls: its code lives where all code does, `src/i<id>.ts`, exporting `i<id>(ctx)`: it throws to fail and returns to pass. Its ctx is a `GateCtx`: the running core, the repo it checks, the bridge, and `out`/`err`.

A gate is linked by what it guards: `test.gate` on a repo's root is run by `nosedive test <repo>`. A gate has no test file of its own, because it is one; and users cannot run it by name.
