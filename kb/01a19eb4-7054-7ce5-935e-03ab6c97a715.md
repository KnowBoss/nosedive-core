# Next

## Usage

`nosedive next` lists what is left to do in the hero, for the pilot and the agents working with them. It writes nothing.

### Trunk first

When the hero has an `origin`, next first fetches it and compares `HEAD` with origin's trunk (`origin/HEAD`). If `HEAD` lacks commits trunk has, it prints `warning: the hero lacks <n> commits origin's trunk has: rebase onto <trunk> before trusting this list` on stderr before the list, which keeps stdout to itself, still lists, and exits 1, saying on stderr that the hero is behind, since a stale hero lists work already done elsewhere and misses work minted there. A hero with no `origin` is listed as it is, and so is one whose `origin` cannot be fetched, offline say, with a line on stderr saying so and why.

### What it lists

It walks the hero's roots once (see feat-tree) and lists two things:

- **Leaves**: each doc the walk reaches whose kind is not durable and that links no `.feat` child of its own, other than by `parent.feat`. A feat's dives are linked `dives.feat`, so each is a leaf of its feat. A durable doc hangs only off a root or another durable doc (see kind), so every non-durable doc is work on the way to something kept, and a leaf is where that work stands.
- **Kind-declared links**: a kind's declaration may name rels in `meta.next`. A doc of that kind, not durable, that a walked doc links by one of them is listed under that doc, though the walk never follows the rel. A question kind that names `open.spec`, as mi's does, lists a feat's unanswered questions under it.

A doc linked by any other rel, such as a memo linked `<sect>.note`, is never listed.

### Output

Each listed doc is printed under the doc that reaches it, the feat or root that links it, in the order the walk met them:

```text
<parent name>  <parent path>
  <kind> <name>  <path>
    done when: <first line of its kind's Done when>
```

Paths are from the hero, with forward slashes, and a kind is named by its shortest spelling: bare for the hero's own, else by its owner's short name, as `core:memo`. A kind is not durable only by having a `## Done when` section (see kind), so every listed doc's kind has one: a section that says nothing prints `done when: its kind's Done when section is empty; read the doc`, and a doc whose kind nothing declares prints `done when: its kind is not declared; read the doc`. With nothing to list, next prints `nothing left to do`.

### Working the list

next only lists. An agent makes a listed doc done, as its Done when and its context call for, then drops it with crud once the pilot agrees: never unasked. A dive is dropped with its feat's `dives.feat` link: `crud <feat> --links` setting the dive's entry to null, then `crud --drop <dive>`.
