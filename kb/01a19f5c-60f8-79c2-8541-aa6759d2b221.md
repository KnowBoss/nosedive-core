# Agent surface

Every agent working in a hero reads the command surface the hero really has, from its instruction files, stamped with the core that wrote it. Seed writes it (see seed); launch reports a block that no longer matches (see launch). It imports launch's rendering of `help --more`, and launch imports its drift check, so it has two users, but a durable function cannot yet hang in a lib memo, so it hangs under seed.

## Files and markers

The instruction files are `AGENTS.md`, `CLAUDE.md`, `GEMINI.md` and `.github/copilot-instructions.md`, in the hero's directory: one list, `INSTRUCTION_FILES`, read by the write and the drift check alike. A file takes part only when it holds both markers, `<!-- BEGIN nosedive managed instructions -->` then `<!-- END nosedive managed instructions -->`, each on a line of its own, the same markers legacy nosedive used. Text outside them is never touched, and the block is never added to a file that exists without them.

## The block

Given the hero's directory, the surface (the text of `nosedive --help --more` as the hero sees it) and core's version, the function replaces what lies between the markers of every marked file with:

1. the stamp, `<!-- nosedive v=<core version> surface=<digest> -->`, the digest being the first 8 hex of the sha256 of the surface, trimmed, so two cores rendering the same surface agree;
2. the guidance: instructions in `nosedive` output come first; a line starting `nose:` is a call to attention, handled before any other work; when the pilot needs help finding work, run `nosedive next`;
3. the surface, fenced with one more backtick than the longest run of backticks in it, and at least three.

When none of the four files exists, it creates `AGENTS.md` holding the markers and the block. When files exist and none is marked, it writes nothing and returns a hint naming the files it looks for and the two marker lines to paste into one, then to run seed again. It returns the paths it changed, a file whose block already reads the same being unchanged, and the hint, if any; it commits nothing.

## Drift

`surfaceDrift(dir, surface)` returns one line for each marked file whose block's stamp digest differs from the surface's, or which carries no stamp: `<file>'s agent instructions do not match this nosedive: run nosedive seed`. No line starts with `nose:`, since it is advice, not a call to attention. Which side is stale is not asked: seed always renders what is installed. Unmarked and missing files say nothing.
