# Run repo tests

Runs `node --test test/*.test.ts` in the repo it is given. The tests import `nosedive-core` and other capes by name, and the child process could find neither, so a resolver passed with `--import` points `nosedive-core` at the running core's module and each cape checked out in the bridge's workspace at its own source. The tests' output goes to `out`; a failing run throws, and so does a repo with no tests, which would otherwise pass.
