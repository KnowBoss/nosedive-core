# The sect and kind a gate usage starts with, pass --<sect> <kind>, or nothing for any other usage

The kind is spelled as crud takes a kind (see find-kind): bare for a kind of the cape that declares the usage, else `<short>:<name>`, `<long>:<name>` or `<quid>:<name>`, so `pass --attach-cape <repo>` in core is core's repo and `pass --land <core:memo>` core's memo.

## Hook gates

A hook gate's usage is `before crud <kind>` or `after crud <kind>` (see crud-gates): its sect is `crud`, and `when` says which. No command line runs one, so `pass` matches none to its argv, and launch refuses one called by name as it refuses any gate.
