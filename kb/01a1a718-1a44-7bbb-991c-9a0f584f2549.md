# Drop when

A kind says how a doc of it is dropped in a `## Drop when` section, which also makes it droppable (see kind; drop-when). Kinds written before say it in `## Done when`. This migration renames that heading to `## Drop when` in every kind doc the repo declares: those in its `.nosedive/kinds/`, and any `kind` doc of core's left in a root's kb, a seeded repo nested in it being left to its own seed. It renames the heading only, never the text under it: a section that says when one is done, rather than how one is dropped, is for the pilot to reword.

A kind doc that has both headings says two things and only the pilot can say which it meant: the migration names each such doc and writes nothing, waiting as a migration does, so seed runs it again once the doc is settled. A doc with no `## Done when` is left as it is, so the migration is safe to run again. It says what it renamed. A kind doc keeps its version, since only its prose changes.
