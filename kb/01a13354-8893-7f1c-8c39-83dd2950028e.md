# Check cape source

One line per problem: a usage that does not start with its action's name; a missing entrypoint, impl or test; an entrypoint that never mentions one of its usage impls; a file under `src/` or `test/` no doc names. `src/main.ts` and `test/harness.ts` are the framework and exempt.
