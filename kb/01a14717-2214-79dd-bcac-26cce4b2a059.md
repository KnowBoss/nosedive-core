# Update kb doc body

Finds the doc as crud's edits do (the bridge, then the workspace's repos), hands its current body and frontmatter to the update, writes what comes back, and commits it in the repo the doc lives in as `crud(<id>): updated <kind> <name>`. The update may throw to refuse the change, and then nothing is written. It returns the doc's path relative to the bridge.
