# Code section

An action's doc has a `## Usage` section, what `--help --more` prints: what each usage does and what to watch for. When a body has none, everything between its title and its `## Code` section becomes it. A function has none.

Any `## Code` section already in the body, up to the next `##` heading, is dropped, and the fresh one goes at the end. scaf writes both and the check refuses a doc whose sections differ, so following the root tree to an action always ends one click from its code.
