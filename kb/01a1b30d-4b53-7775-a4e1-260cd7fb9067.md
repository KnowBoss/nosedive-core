# Run cape migrations

Runs the migrations of the capes a repo wears, after core's (cape-migration-order): for each worn cape with a build for the running core, in the order its root wears them, the cape's `migration` docs, each run by its code in the build, in the chain their `meta.after` makes (the first names none of the cape's). Config `migrations` lists each that ran as `<cape repo id>:<migration id>` (cape-migration-ids), in its own commit `migrate: <cape>:<name>`, as run-migrations commits core's. One that waits, returning nothing, holds back that cape's later migrations and no other cape's. A cape with no build for this core is passed over; seed builds capes first. Removing an entry runs that migration again, so each must be safe to rerun. It returns the names of those that changed something.
