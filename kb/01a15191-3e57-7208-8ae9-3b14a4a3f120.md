# Installs the npm packages a cape's lockfile pins, without running their scripts, unless that lockfile is installed already

## Install

A repo whose `package.json` names no `dependencies` needs nothing. One that does must have a `package-lock.json`, or it is refused. The packages are installed with `npm ci --ignore-scripts`, so no package runs code while a cape builds, and the lockfile's hash is kept in `node_modules/.nosedive-lockfile`, so the next build installs again only when the lockfile changed. A clone has `node_modules/` excluded from git.
