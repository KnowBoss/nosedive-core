# Hero

The hero itself is its primary root, the root whose id is config id. Seed --workspace writes a new one in self/<quid>.md. It holds the hero own feats, dives and decisions and wears its capes through cape-role links. Hero is a structural core kind with closed empty meta and durable identity, like base and cape. Config workspace still enables work; the kind names what the root is. Further roots may be bases. Existing heroes keep their configured root path; hero-self changes a primary core base to core hero without moving docs.
