# Base

A hero's roots are bases: `nosedive seed --workspace` makes one. The primary root, the one whose id is config `id`, is the home base; any other is an away base. Each base works the feats it reaches and wears its own capes, linking each by its repo doc with a rel whose role is `cape`, `.cape` while no sect is wanted (see configured-capes). The base selected, the home base unless `--base` names another, decides which capes are in use (see launch).

A cape's root is of kind `cape`, and a repo of data's is a `base` with no workspace: what a root is says what its repo is for.
