# Base

The kind of an older data repo's root: docs, and artifacts beside them, with no workspace, no capes and no actions; a hero repo checks it out in its workspace, and a doc written into it is checked against the hero's kinds, then the capes'. Seed makes no new ones: a repo of data is one whose config has neither a workspace nor a cape root.

Before hero repos, a base was the repo a team worked from. A legacy `base` root that carries `meta.workspace` is still read that way, its workspace being that path; the schema keeps `workspace` for it.
