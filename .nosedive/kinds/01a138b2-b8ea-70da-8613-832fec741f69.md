# Memo

The one open kind. A memo becomes a root, a feat or a grouping by how it is linked, not by its kind. It is durable: a note, a root or a grouping has no state in which it is done, so it is kept until someone drops it on purpose (`crud --drop --hard`). Work, which is done at some point and then dropped, is of a kind that says when, such as a hero's goal; core declares none, since passing work belongs to the bridge that does it (see kind).
